# 校园网使用条款与责任声明

> 上线前请把这一页读完。它不解决技术问题，但它决定你该不该在这张网络里用这套东西。

## 1. 技术能力 ≠ 使用授权

本固件包含这些能力：一台设备代多台终端上网（NAT）、IPv6 地址转换（NAT66）、把内网终端藏在同一个出口后面、统一出向 TTL 与屏蔽部分广播报文（防检测）、透明代理。

**这些能力在技术上成立，不代表你在某张具体网络上有权使用。**授权来自你所在学校的网络使用协议，而不是来自这个固件。

## 2. 多数高校校园网条款里常见的限制

不同学校表述不同，但高频出现的是这几条（以你学校的正式文本为准）：

| 条款类型 | 典型表述 | 与本固件的关系 |
|---|---|---|
| 账号实名与本人使用 | 「账号仅限本人使用，不得转借、共享」 | 一台路由让全宿舍上网，通常落在这一条里 |
| 禁止私接路由/共享设备 | 「禁止使用路由器、随身 WiFi 等方式共享网络」 | 本固件正是这类用途 |
| 按设备数计费/限速 | 「同一账号最多 N 台设备同时在线」 | NAT/NAT66 会让校园侧只看到一台设备 |
| 指定客户端 | 「须使用学校提供的认证客户端」 | minieap 是第三方客户端，不是官方客户端 |
| 禁止绕过计费与认证 | 「不得以任何方式绕过认证、计费或流量统计」 | 防检测功能属于风险最高的部分 |
| 禁止转售/牟利 | 「不得利用校园网从事经营性活动」 | 拿它给非本校人员提供接入即属此类 |

**结论**：这套固件在「学校允许自建小型网络」或「默许单账号单路由」的环境里才是合规的。学校明文禁止时，用它是违规行为，被抓到通常是断网、通报或纪律处理，与固件质量无关。

## 3. 本固件做了什么、不做什么

做：

- 用**你自己的账号和密码**、走标准 802.1x/EAP 流程完成锐捷认证（minieap rjv3）。
- 网络层特征归一：出口 TTL 统一、屏蔽部分外泄广播、WAN 禁入站、统一 DHCP 指纹。
- 地址转换：让下联设备共用一个出口地址。

不做：

- 不伪造身份、不冒用他人账号、不破解或绕过认证算法。
- 不做心跳伪造、不做定时重认证来骗过在线检测。
- 不隐藏「有人在使用认证账号」这件事本身——认证记录里永远是**你的账号**。
- 不提供任何规避监管、攻击、抓取他人数据的能力。

换句话说：它把你的多台设备伪装成「一台设备的正常流量特征」，但认证主体仍然是你，**责任主体也仍然是你**。

## 4. 责任声明

1. **账号持有人承担全部责任**。使用本固件产生的一切后果，包括但不限于账号封禁、限速、断网、纪律处分、法律责任，由账号持有人自行承担。
2. **下联设备的行为算在你头上**。任何人通过你的路由访问网络，源头上都指向你的账号。
3. **不提供担保**。固件按「现状」提供，不附带任何明示或暗示担保；因刷写、配置、使用导致的设备损坏、数据丢失、网络中断，作者不承担责任。
4. **遵守当地法律与学校规章**。使用前自行确认你所在学校/单位的网络管理规定；不清楚就先问网络中心，别先接线。
5. **不要用它做这些事**：转售带宽、给校外人员提供接入、规避计费、隐藏违法活动、扫描或攻击他人网络。

## 5. 被检测/被处置时怎么办

出现「认证失败」「账号异常」「被要求到网络中心说明」时，按顺序做：

```sh
campus-guard clear                 # 1. 先关掉防检测规则（这是最容易引起注意的部分）
wanmode show                       # 2. 确认当前 WAN 是什么模式
ifstatus wan                       # 3. 确认认证是否正常
```

1. 立刻关防检测（上面前两条），恢复到「普通单机上网」状态。
2. 用学校官方客户端验证账号本身是否正常（欠费、被停用、被限速）。
3. 主动联系网络中心，如实说明用途。**隐瞒或继续加装绕过手段通常会让处理升级。**
4. 学校明确不允许共享接入时，就不要再开：改用官方多设备方案，或只让一台设备上网。

## 6. 隐私与数据处理

- **透明代理**（nikki）会看到经过它的流量元数据（访问的域名、连接时间）。订阅节点由第三方提供，等于把访问记录交给服务商；敏感场景下不要开，或明确知道自己选的是哪家节点。
- **抓包排障**（`tcpdump`）会把认证报文、DHCP 交互写进 pcap，其中可能包含账号与内网设备信息。排障完及时删除，不要把 pcap 传到公开群组。
- **配置备份**（`sysupgrade -b`）里含账号、密码、代理订阅，等同于密钥文件，别丢在公共网盘。
- 本固件不向任何服务器上传遥测数据；是否能上网完全取决于你自己的认证与代理配置。

## 7. 合规使用建议

- 先读学校的《校园网用户手册 / 网络使用管理办法》，重点看「能否使用路由器」「设备数限制」「是否必须用指定客户端」。
- 学校提供官方的多设备或宿舍路由备案方案时，优先走官方渠道。
- 只在**你自己承担费用与责任**的账号上使用，不要用它接入别人的账号。
- 出了网络问题，第一时间关掉所有「增强」功能（防检测、代理），先恢复最小可用状态再排查。
- 记住一句话：**这个固件能降低「被误判成异常设备」的概率，不能给你任何合法性。**
